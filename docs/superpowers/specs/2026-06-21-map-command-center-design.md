# 地图指挥台 UI 重构设计

## 1. 目标

将当前三栏管理界面重构为“地图指挥台”：

- 高德地图成为第一视觉主体，占满整个网页页面。
- 删除冗余状态文案，例如“已接入高德地图；筛选结果会同步为真实地图标记。”和“本地优先 · IndexedDB 自动保存”。
- 搜索框固定在地图正上方居中，作为主入口。
- 筛选、结果列表、店铺详情、备份、新增店铺等功能改为按需展开，默认不挤占地图空间。
- 保留现有温暖、克制、编辑部地图的字体和视觉气质，但布局不再是左中右三栏。

## 2. 非目标

本轮不做以下事项：

- 不改数据库 schema。
- 不改 Dexie repository、备份格式、评分算法、筛选算法。
- 不引入登录、云同步、公开分享页。
- 不重写高德适配器核心逻辑，只调整使用方式和 UI 容器。
- 不新增复杂路线规划、导航、实时营业状态。
- 不做 marker 聚合，除非高德默认显示在当前缩放下明显不可用。

## 3. 桌面布局

默认首屏结构：

```text
┌──────────────────────────────────────────────┐
│              居中搜索框                       │
│  品牌按钮                           操作按钮  │
│                                              │
│                                              │
│               高德地图全屏                    │
│                                              │
│                                              │
│  筛选按钮    结果胶囊/底部条        详情抽屉  │
└──────────────────────────────────────────────┘
```

### 3.1 常驻元素

只保留这些常驻元素：

- 左上角品牌按钮：`饭`，点击打开应用菜单。
- 顶部居中搜索框：搜索店名、地址、备注、POI。
- 右上角操作组：
  - 新增店铺。
  - 导入备份。
  - 导出备份。
- 左下角筛选按钮：打开筛选面板。
- 底部结果摘要：显示当前结果数量和可横滑的精简店铺卡片。

### 3.2 默认隐藏元素

这些元素默认不常驻：

- 全量筛选栏。
- 右侧详情面板。
- 消费记录表单。
- 删除店铺按钮。
- 详细评分条。
- 备份说明文字。
- 地图状态说明文字。

## 4. 面板与交互

### 4.1 搜索框

搜索框位于页面正上方，悬浮在地图上。

行为：

- 输入时仍使用现有本地筛选 query。
- 后续可以扩展为本地店铺搜索 + 高德 POI 搜索的组合结果。
- 清空搜索后恢复当前筛选结果。
- 搜索框不显示“本地优先”等状态说明。

首版重构中，搜索框先绑定现有 `filters.query`，不新增复杂 command palette。

### 4.2 筛选面板

点击左下角“筛选”按钮后，从左侧滑出窄面板。

面板内容复用现有筛选能力：

- 状态 segmented control。
- 主类型 chips。
- 标签 chips。
- 综合分 range slider。
- 人均 range slider。
- 排序 select。
- 当前结果数量。

边界：

- 面板打开时地图仍可见。
- 面板宽度桌面端不超过 340px。
- 面板关闭后不保留空白占位。

### 4.3 结果条

底部显示一条横向结果条。

默认状态：

- 显示当前结果数量。
- 显示 3-5 个精简店铺卡片。
- 卡片只显示类型、店名、综合分、人均。

交互：

- 点击卡片选择店铺并聚焦地图 marker。
- 可以横向滚动。
- 当筛选结果为空时显示简短空状态。

边界：

- 不再让结果条占据大块页面高度。
- 不显示复杂说明文字。

### 4.4 店铺详情抽屉

点击 marker 或结果卡片后，从右侧打开详情抽屉。

详情抽屉内容：

- 店名、状态、地址。
- 综合分。
- 类型、人均、消费次数。
- 标签。
- 分项评分。
- 笔记。
- 消费记录时间线。
- 新增消费记录表单。
- 删除店铺按钮。

交互：

- 抽屉可以关闭。
- 关闭后仍保留地图和选中 marker。
- 桌面宽度下抽屉不超过 380px。
- 移动端改为底部 sheet。

边界：

- 首轮不拆消费记录编辑。
- 首轮不新增店铺编辑。

### 4.5 新增店铺

点击右上角新增按钮打开现有新增店铺 Dialog。

保留：

- 高德 POI 搜索选点。
- 手动填写店名、地址、坐标。
- 状态、类型、标签、人均、评分、笔记。

调整：

- Dialog 可以适当收窄或分区，但本轮不改核心字段。

## 5. 移动端布局

移动端采用地图全屏 + 底部 sheet：

- 顶部搜索框保持居中，但宽度适配。
- 筛选面板变为底部 sheet。
- 店铺详情也变为底部 sheet。
- 结果条默认显示在底部，避免遮挡顶部搜索。

移动端验收：

- `390x844` 无横向溢出。
- 搜索框、筛选按钮、新增按钮可点击。
- 高德地图仍可拖动缩放。

## 6. 组件边界

本轮需要从 `src/App.tsx` 中拆出或至少建立清晰内部边界：

- `MapCommandShell`：新主布局容器。
- `MapSearchBar`：顶部搜索框。
- `FloatingActionBar`：右上角新增、导入、导出。
- `FilterDrawer`：筛选抽屉。
- `ResultDock`：底部结果条。
- `PlaceDetailsDrawer`：右侧或底部详情抽屉。
- `MapCanvas`：高德地图挂载与 fallback。

代码边界：

- 组件不直接调用 Dexie。
- 组件不直接调用 `AMap` 全局对象。
- 高德仍只通过 `MapAdapter`。
- 筛选和排序仍通过现有纯函数。

## 7. 状态模型

新增 UI 状态可以放入 `uiStore`：

- `filterDrawerOpen: boolean`
- `detailsDrawerOpen: boolean`
- `resultDockExpanded: boolean`

已有状态继续复用：

- `filters`
- `sortKey`
- `selectedPlaceId`

规则：

- 点击 marker 或结果卡片时，设置 `selectedPlaceId` 并打开详情抽屉。
- 点击地图空白区域是否关闭详情，本轮暂不实现，避免与高德地图事件耦合。
- 搜索框输入只更新 `filters.query`。

## 8. 视觉规范

保留：

- serif 标题气质。
- 米白、墨黑、暖灰、番茄红、橄榄绿、金色。
- 8px 或更小圆角，浮层可使用 12-16px 但不做卡片堆卡片。
- 克制阴影和半透明纸面质感。

调整：

- 页面背景由高德地图承载，不再使用大面积纸面背景。
- 顶部标题不再常驻显示大 H1。
- 删除所有解释性地图状态文案。
- 控件要像地图应用的工具层，而不是传统后台表单。

## 9. 错误与空状态

- 未配置高德 Key：地图区域显示配置提示和本地兜底入口，但不再伪装成艺术地图。
- 高德加载失败：显示简短错误浮层，并允许继续使用列表和手动新增。
- 搜索无结果：底部结果条显示“没有符合条件的店”。
- Dexie 加载中：只显示小型 loading 点或骨架，不显示长句说明。

## 10. 测试与验收

自动化验证：

- `pnpm check`
- `pnpm test`
- `pnpm build`

组件/单元补充：

- App shell 渲染新搜索框。
- 筛选抽屉打开/关闭。
- 点击结果卡片打开详情抽屉。
- 无 Key 时不显示艺术地图伪装状态。

浏览器视觉验收：

- `1440x900`：地图占据主要视口，搜索框居中，详情/筛选默认不占常驻宽度。
- `1280x720`：顶部搜索和右上角操作不重叠。
- `390x844`：无横向溢出，底部 sheet 可用。
- 配置高德 Key 时，地图区域是真实高德底图，不出现本地艺术地图。

## 11. 实施顺序

1. 删除冗余文案和旧三栏常驻布局。
2. 建立 `MapCommandShell` 全屏地图布局。
3. 接入顶部居中搜索框和右上角操作组。
4. 将左侧筛选改为抽屉。
5. 将店铺列表改为底部结果条。
6. 将详情面板改为右侧抽屉。
7. 调整移动端底部 sheet。
8. 更新文档、进度清单和对齐检查。
9. 运行测试、构建和浏览器视觉验收。

## 12. 待确认点

本设计默认：

- 桌面端详情从右侧打开。
- 移动端详情从底部打开。
- 结果条常驻在底部，但高度保持克制。
- 无 Key 时不再显示艺术地图，而是显示配置提示。

如果这些默认边界成立，可以进入实现计划。
